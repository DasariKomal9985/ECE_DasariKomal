Important Embedded C Patterns
• Bit operations: set, clear, toggle, read, masking, extraction, insertion.
• Memory: stack, heap, data/BSS, static storage, pointers, dynamic allocation, lifetime.
• Function pointers: callbacks, command tables, driver interfaces, state machines.
• Data structures: singly, doubly, and circular linked lists; loop/cycle problems.
• Buffers: arrays, circular buffers, FIFO/ring buffers, UART packet parsing.
• Hardware-style practice: GPIO/status/control registers, ADC, PWM, timers, UART.
