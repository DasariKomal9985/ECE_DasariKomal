1. Union in C
Definition: A union is a user-defined data type in C that allows multiple members of different data types to share the same memory location. 
All members share the same memory, but only one member's value should be considered

Syntax:
union UnionName
{
    int a;
    float b;
    char c;
};









2. Union Initialization
Definition: Union initialization is the process of assigning an initial value to a union member when declaring a union variable.


union Data
{
    int number;
    float value;
    char letter;
};

union Data d = {10};

Here:
- d is a union variable.
- number is initialized to 10.
- If using a normal initializer list without a designated member, the first member is initialized.

You can also use a designated initializer:
union Data d = {.value = 25.5};
Here, value is initialized to 25.5.











3. Accessing Union Members
Definition: Union members are accessed using the dot (.) operator through a union variable or the arrow (->) operator through a pointer to a union.

d.number = 100;
printf("%d", d.number);

d.number accesses the number member.
d.value accesses the value member.
d.letter accesses the letter member.

Important: Writing to one member changes the shared memory representation. Reading a different member afterward is generally implementation-dependent and may produce an interpreted representation rather than the original value.









4. Structure vs Union
Definition of structure: A structure is a user-defined data type that groups multiple members of different data types, with separate storage for each member.

Definition of union: A union is a user-defined data type that groups multiple members of different data types, with all members sharing the same memory location.










5. Memory Allocation in Union
Definition: In a union, memory is allocated as one shared storage area large enough and suitably aligned for its largest member.

union Data
{
    int a;       // 4 bytes
    float b;     // 4 bytes
    char c;      // 1 byte
};

Assuming int and float are 4 bytes and the alignment requirements permit it:
- a requires 4 bytes.
- b requires 4 bytes.
- c requires 1 byte.
- Union size is typically 4 bytes, not 9 bytes.

6. Importance of Union in Embedded C
Definition: Unions are important in Embedded C because they allow different data representations to share the same memory, helping reduce RAM usage and support hardware-level data handling.

Common applications:
- Register representation.
- Protocol packet handling.
- Memory-efficient data representation.
- Data conversion and byte-level inspection.








Structure → Separate memory for each member.
Union → Shared memory for all members.
Union size → Determined by the largest member's storage and alignment requirements.
Union → Useful for memory-efficient data handling in Embedded C. 🔧














#include <stdio.h>
#include <string.h>

union Data
{
    int number;
    float value;
    char name[20];
};

int main(void)
{
    union Data d = {.number = 100};

    printf("Integer Value = %d\n", d.number);

    d.value = 25.5;

    printf("Float Value = %.2f\n", d.value);

    strcpy(d.name, "Komal");

    printf("String Value = %s\n", d.name);

    printf("Union Size = %zu bytes\n", sizeof(d));

    return 0;
}


Integer Value = 100
Float Value = 25.50
String Value = Komal
Union Size = 20 bytes










6.1 Register Representation
Definition: Union can be used to represent a hardware register as both a complete integer value and individual fields or bytes, making it easier to access different parts of the register.

For example, a 32-bit register can be viewed as one 32-bit value or four 8-bit bytes.

Note: Bit-field layout and byte order are compiler- and processor-dependent, so hardware register code must follow the MCU documentation.




6.2 Protocol Packets
Definition: Unions can be used in protocol packet handling to represent the same packet data in different formats, such as a complete integer value or individual bytes.

For example, a 32-bit packet field can be accessed as four separate bytes.




6.3 Memory-Efficient Data Representation
Definition: Unions help reduce memory consumption by allowing multiple data types to share the same memory area when those values are not required simultaneously.

For example, an embedded device may use the same memory location to store a temperature value, an error code, or a communication value at different times.
