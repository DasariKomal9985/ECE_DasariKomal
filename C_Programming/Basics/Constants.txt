A constant is a fixed value that does not change during program execution.



Constant = Fixed value




| Feature | Constant | Variable |
|---|---|---|
| Value | Fixed | Can change |
| Example | `100` | `int x` |
| Can modify? | No | Yes |
| Example | `3.14` | `float voltage` |




#define LED_PIN 5

const uint32_t BAUD_RATE = 115200;

uint8_t data = 0x55;
float voltage = 3.3;
