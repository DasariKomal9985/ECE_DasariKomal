Type Casting in C
1. Definition
Type casting is the process of converting a variable or expression from one data type to another data type.

2. Types of Type Casting
There are two types:
Implicit Type Casting (Automatic Conversion)
Explicit Type Casting (Manual Conversion)

3. Implicit Type Casting
Definition: Implicit type casting is the automatic conversion of one data type into another data type by the compiler without requiring the programmer to specify the conversion.
Example:
#include <stdio.h>

int main(void)
{
    int a = 10;
    float b = 5.5;

    float result = a + b;

    printf("Result = %.2f\n", result);

    return 0;
}

Explanation:
a is an integer.
b is a float.
During addition, a is converted to float.
The result is 15.5.


Explicit Type Casting
Definition: Explicit type casting is the manual conversion of one data type into another data type by the programmer using the cast operator.

Syntax:
(data_type) expression;

Example:
#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 3;

    float result = (float)a / b;

    printf("Result = %.2f\n", result);

    return 0;
}


Explanation:
(float)a converts integer a into a float for this expression.
Division is performed using floating-point arithmetic.
Result is 3.333....

Without type casting:
float result = a / b;
The result would be 3.00 because integer division happens first, and then the result is converted to float.

The result would be 3.00 because integer division happens first, and then the result is converted to float.
5. Difference Between Implicit and Explicit Type Casting
Implicit Explicit
Automatic conversion. Manual conversion.
Performed by compiler. Specified by programmer.
No cast operator required. Uses cast operator (type).
Example: float x = 10; Example: float x = (float)10;




6. Important Points
Type casting converts values between data types.
Implicit conversion is performed automatically by the compiler.
Explicit conversion is performed using the cast operator.
Converting float to int removes the fractional part; it does not round.
Converting a larger integer type to a smaller one may lose information.
Type casting is useful in calculations, data conversion, and embedded programming.


#include <stdio.h>

int main(void)
{
    unsigned int adc_value = 2048;

    float voltage;

    voltage = ((float)adc_value / 4095) * 3.3f;

    printf("Voltage = %.2f V\n", voltage);

    return 0;
}


Voltage = 1.65 V

Remember:
Implicit → Compiler converts automatically.
Explicit → Programmer converts manually using (data_type). 🔧
