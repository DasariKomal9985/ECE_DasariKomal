 What is a Function?
A function is a block of code designed to perform a specific task.

Instead of writing the same code repeatedly, we can put it inside a function and call it whenever required.
Example concept
main()
  ↓
function call
  ↓
function executes
  ↓
returns result
  ↓
main()

Functions help with:
- Code reusability
- Modularity
- Readability
- Debugging
- Maintenance




Function Declaration / Prototype
A function declaration tells the compiler about a function before it is called.

It specifies:
- Return type
- Function name
- Parameter types
Syntax
return_type function_name(parameter_types);

Example:
int add(int, int);

This tells the compiler:
There is a function named add that takes two int parameters and returns an int





Function Definition
A function definition contains the actual implementation or body of the function.

Example:
int add(int a, int b)
{
    return a + b;
}

Here:
int              → Return type
add              → Function name
int a, int b     → Parameters
{ ... }          → Function body
return a + b     → Return value




Function Call
A function call is used to execute a function.

Example:
result = add(10, 20);

Here add() is called with 10 and 20.
Execution goes to:
int add(int a, int b)
{
    return a + b;
}

Then execution returns to the calling code.




Parameters
Parameters are variables declared in a function definition that receive values when the function is called.

Example:
int add(int a, int b)

Here:
a → Parameter
b → Parameter

Parameters are also called formal parameters.




Return Value
A return value is the value sent back from a function to its caller using return.

Example:
int add(int a, int b)
{
    return a + b;
}

If:
add(10, 20);

The function returns:
30

A function can return different data types:
int getNumber(void);
float getVoltage(void);
char getGrade(void);

A function that returns nothing uses:
void display(void);




Actual and Formal Arguments
Formal Arguments / Parameters
The variables written in the function definition.
int add(int a, int b)

a and b are formal parameters.
Actual Arguments
The values supplied during the function call.
add(10, 20);

10 and 20 are actual arguments.
Easy way to remember
Function definition:
add(int a, int b)
     ↑       ↑
   Formal  Formal

Function call:
add(10, 20)
    ↑    ↑
  Actual Actual




Call by Value
In call by value, a copy of the argument's value is passed to the function.

Example concept:
main()
 x = 10
   ↓
 copy of 10
   ↓
function parameter

Changing the parameter does not change the original variable.
void change(int x)
{
    x = 50;
}

If:
int a = 10;
change(a);

After the function:
a = 10

Important C point ⚠️
C uses pass-by-value.
Even when you pass a pointer, the pointer itself is passed by value.





Call by Reference
Example concept:
void change(int *x)
{
    *x = 50;
}

Call:
int a = 10;

change(&a);

Now:
Before → a = 10
After  → a = 50

Flow
a
↓
&a
↓
pointer x
↓
*x
↓
original a

This is commonly called call by reference in C, but technically it is passing a pointer by value.




Function Prototype
A function prototype is a declaration that tells the compiler the function's:
Name
Return type
Parameter types

Example:
int add(int a, int b);

You can also write:
int add(int, int);

The parameter names are optional in a prototype.





Nested Function Calls
A nested function call occurs when the result of one function call is used as an argument to another function call, or one function calls another.

Example:
printf("%d\n", add(10, 20));

Here:
add()
 ↓
30
 ↓
printf()

Another example:
int square(int x)
{
    return x * x;
}

int add(int a, int b)
{
    return a + b;
}

A call can be:
square(add(2, 3));

Execution:
add(2,3)
   ↓
   5
   ↓
square(5)
   ↓
  25





Recursion
Recursion is a technique where a function calls itself.

Example:
void count(int n)
{
    if (n == 0)
        return;

    printf("%d\n", n);

    count(n - 1);
}

Calling:
count(5);

creates:
count(5)
  ↓
count(4)
  ↓
count(3)
  ↓
count(2)
  ↓
count(1)
  ↓
count(0)
  ↓
return

Every recursive function needs:
1. Base condition
2. Recursive call
Without a proper base condition, recursion can continue until the program runs out of stack space.





Scope of a Function
A function has a scope-related distinction that is important:
Function definition scope
A function can normally be called from other functions when its declaration is visible.
Example:
int add(int, int);

int main(void)
{
    add(10, 20);
}

Local variables
Variables declared inside a function are normally accessible only within that function.
void test(void)
{
    int x = 10;
}

x cannot directly be accessed from main().
Global variables
Variables declared outside functions can have file scope.
int x = 10;

void test(void)
{
    printf("%d\n", x);
}





Function Pointer
A function pointer is a pointer that stores the address of a function.

Normal pointer
int *p;

Points to data.
Function pointer
int (*fp)(int, int);

Points to a function that:
- Takes two int parameters
- Returns an int
Example:
int add(int a, int b)
{
    return a + b;
}

int (*fp)(int, int);

fp = add;

Now:
fp(10, 20);

calls add().
Common Embedded C uses 🔧
Function pointers are widely used for:
- Interrupt/callback handlers
- Driver interfaces
- State machines
- Function tables
- Command handlers
- HAL interfaces
