 Stack – Local Variables
Definition: The stack is a memory region used for function calls, local variables, return addresses and saved registers.

From our code:
int main(void)
{
    int a = 10;
    int b = 20;
}
And:
void my_function(void)
{
    int local_var = 10;
}
These are automatic local variables.
Where are they stored?
When main() executes, its function stack frame may contain a and b.
When my_function() is called, another stack frame is created for its execution.

When the function returns, its stack frame is released.
Conceptually:
STACK (SRAM)

+----------------------+
| my_function() frame  |
| local_var            |
| saved registers      |
+----------------------+
| main() frame         |
| a                    |
| b                    |
| return information   |
+----------------------+



Actual variable placement can differ because the compiler may use CPU registers or optimize variables away.
Important: Stack memory is automatically managed as functions are called and returned. It is not manually allocated using malloc().


Heap – Dynamic Memory Allocation
Definition: Heap is a memory region used for allocating memory dynamically during program execution.

From our code:
int *ptr = malloc(sizeof(int));
Here, two things happen:
ptr is a local pointer variable. It is typically stored on the stack.
malloc() allocates space for an integer from the heap.
Then:
*ptr = 500;
The value 500 is stored in the dynamically allocated heap memory.

Finally:
free(ptr);
The allocated memory is released for reuse.
Conceptually:
STACK (SRAM)             HEAP (SRAM)

+-------------+          +-------------+
| ptr         |--------->| Value = 500 |
+-------------+          +-------------+Stack Heap
Automatic memory management Manual allocation/release
Local variables Dynamic variables
Function calls malloc/calloc/realloc
Released when function returns Released using free()
