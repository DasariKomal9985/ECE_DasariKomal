What is Memory Architecture?
Definition: Memory architecture describes how memory is organized and used in a computer or microcontroller to store program instructions, data and intermediate results during execution.

A processor needs memory for two major purposes:

Program storage: Stores the firmware instructions.
Data storage: Stores variables, temporary data, stack, heap and other runtime information.

For embedded systems, the important memory types are:

RAM (Random Access Memory)
ROM (Read Only Memory)
SRAM (Static RAM)
DRAM (Dynamic RAM)
Flash Memory
EEPROM (Electrically Erasable Programmable ROM)












RAM (Random Access Memory)

Definition: RAM is a volatile memory that temporarily stores data and instructions required by the processor during program execution. Its contents are lost when power is removed.

Characteristics:

Volatile memory.
Read and write operations.
Fast access.
Used for temporary data storage.
Data is lost when power is switched OFF.

Example:
int a = 10;
int b = 20;
int c = a + b;

When this program executes, variables and intermediate data are handled using RAM and CPU registers, depending on compiler optimization and variable placement.

Important: RAM is a general category. SRAM and DRAM are two major types of RAM.














ROM (Read Only Memory)

Definition: ROM is a non-volatile memory used to store data or instructions that must be retained even when power is removed.

Characteristics:

Non-volatile memory.
Retains data without power.
Traditionally designed for read-only operation.
Used for permanent firmware or fixed data.

Types of ROM:

Type          Meaning
Mask ROM      Programmed during manufacturing
PROM.         Programmable once
EPROM         Erased using ultraviolet light
EEPROM        Electrically erasable and programmable

Important: Modern embedded microcontrollers commonly use Flash memory instead of traditional ROM because Flash can be electrically erased and reprogrammed.












SRAM (Static RAM)
Definition: SRAM is a type of volatile RAM that stores each bit using a flip-flop-based circuit and retains data as long as power is supplied, without requiring periodic refreshing.

Characteristics:

Volatile memory.
Very fast.
No refresh operation required.
More expensive per bit.
Requires more chip area per bit.
Commonly used as CPU cache and microcontroller working memory.

Example: STM32F401

The STM32F401RB has:
128 KB Flash memory.
64 KB SRAM.

When your firmware runs, SRAM is used for:

Global variables.
Local variables.
Stack.
Heap (if dynamically allocated).
Temporary runtime data.
