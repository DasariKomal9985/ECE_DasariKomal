16. DAC — Digital-to-Analog Converter 🔌
DAC is an important topic in Embedded C. We learned that an ADC converts an analog voltage into a digital value. A DAC does the opposite: it converts a digital value into an analog output voltage.
For example, a microcontroller can use a DAC to generate a variable voltage, produce audio signals, or generate waveforms such as sine waves.






1. Digital → Analog
What is a DAC?
DAC stands for Digital-to-Analog Converter. It converts a digital number from a microcontroller into a corresponding analog output.
Why do we use it?
A microcontroller works with digital data, but some applications need a continuously varying voltage output.
Examples:
- Generating audio signals.
- Producing a reference voltage.
- Generating sine, triangle, or other waveforms.
- Controlling external analog circuits.
- Testing and calibrating electronic equipment.
How does it work?
Suppose an MCU sends the digital value 2048 to a 12-bit DAC with a 3.3 V reference.
The DAC converts that code into an output voltage of approximately half the reference voltage.
For an ideal 12-bit DAC:
\[
V_{\text{out}}=\frac{D}{2^N-1}\times V_{\text{ref}}
\]

Where:
- \(D\) = digital input code.
- \(N\) = DAC resolution in bits.
- \(V_{\text{ref}}\) = reference voltage.
For this example:
\[
V_{\text{out}}=\frac{2048}{4095}\times3.3
\approx1.65\text{ V}
\]

The DAC produces an analog voltage corresponding to the digital input code, within its electrical limits.
Remember: ADC converts analog to digital; DAC converts digital to analog.






2. DAC Resolution
What is resolution?
DAC resolution determines how many discrete output codes the DAC can accept and how finely it can adjust its ideal output voltage.
The number of possible codes is:
\[
\text{Number of codes}=2^N
\]

DAC resolution	Number of codes	Digital code range
8-bit	256	0–255
10-bit	1,024	0–1,023
12-bit	4,096	0–4,095
16-bit	65,536	0–65,535
Example: 12-bit DAC
A 12-bit DAC accepts 4,096 different digital codes. With a 3.3 V reference, the ideal voltage step is approximately:
\[
\text{Step size}=\frac{3.3}{4095}
\approx0.806\text{ mV}
\]

This is the nominal difference between adjacent ideal output levels under the stated convention.
Why is resolution important?
Higher resolution allows finer voltage adjustments. However, actual output accuracy also depends on DAC errors, reference quality, and the output circuitry.






3. Reference Voltage
What is reference voltage?
The reference voltage sets the scale for the DAC's output.
For example, a DAC using a 3.3 V reference can ideally produce output levels from approximately 0 V up toward 3.3 V, depending on the DAC design and output limits.
Why is it important?
The reference voltage determines the relationship between the digital input code and the analog output.
For the same digital code:
- A 3.3 V reference produces one output voltage.
- A 2.5 V reference produces a lower output voltage.
The exact relationship depends on the DAC's transfer function.
Important: The reference voltage and maximum usable output voltage are not always identical. Check the specific MCU datasheet.






4. Output Voltage
What is output voltage?
Output voltage is the analog voltage generated by the DAC in response to its digital input code.
For an ideal 12-bit DAC, the output can be estimated using:
\[
V_{\text{out}}=\frac{D}{4095}\times V_{\text{ref}}
\]

Assuming a 3.3 V reference:
Digital input	Approximate output
0	0 V
1024	0.825 V
2048	1.65 V
3072	2.476 V
4095	3.3 V
These are idealized values. The actual output depends on the DAC's specifications and electrical conditions.
Embedded C example
uint32_t dac_value = 2048;
float voltage;

voltage = (dac_value * 3.3f) / 4095.0f;


This calculates the ideal voltage represented by the code. It does not configure the DAC or physically generate the voltage; you must write the code to the DAC peripheral.






5. DAC Channel
What is a DAC channel?
A DAC channel is an independent DAC output path that can generate an analog signal.
Some microcontrollers have one DAC channel, while others have multiple channels.
For example, if an MCU has two DAC channels, you may be able to generate two independent analog voltages.
Why is it used?
- One channel can generate a reference voltage.
- Another can generate a waveform.
- Two channels can generate separate signals or coordinate their outputs.
STM32 note: DAC availability depends on the exact MCU. The STM32F401RBT6 does not have an on-chip DAC peripheral, so you would need a different STM32 model with DAC support or an external DAC IC to practice these examples on hardware.






6. Waveform Generation
What is waveform generation?
Waveform generation means creating a voltage that changes over time according to a particular pattern.
Common waveforms include:
- Sine wave: Smooth, periodic oscillation.
- Triangle wave: Voltage rises and falls linearly.
- Sawtooth wave: Voltage ramps up or down, then resets.
- Square wave: Alternates between two levels; often generated more directly using GPIO or timers.
How does a DAC generate a waveform?
1. Store digital values representing the desired waveform.
2. Send each value to the DAC in sequence.
3. The DAC converts each value into an output voltage.
4. Repeat the sequence to generate a periodic waveform.
For example, increasing codes produce increasing output voltage; decreasing codes produce decreasing output voltage.
The output changes in discrete steps. Filtering may be used when a smoother waveform is required.






7. Sine Wave Generation
What is sine wave generation?
Sine wave generation means producing an analog voltage that follows a sine-shaped pattern over time.
A DAC can generate a sine wave by outputting a sequence of digital samples that represent one cycle of a sine function.
Step 1: Calculate sample values
A sine wave can be represented by:
\[
V(t)=V_{\text{offset}}+A\sin(2\pi ft)
\]

Where:
- \(V_{\text{offset}}\) = center voltage.
- \(A\) = amplitude.
- \(f\) = frequency.
For a unipolar DAC, the offset can be set near half the reference voltage so the waveform remains within the DAC's output range.
Step 2: Store sample values
For a 12-bit DAC, you can store values between 0 and 4095 in an array.
#define NUM_SAMPLES 32

uint16_t sine_table[NUM_SAMPLES] = {
    2048, 2447, 2831, 3185,
    3495, 3750, 3939, 4056,
    4095, 4056, 3939, 3750,
    3495, 3185, 2831, 2447,
    2048, 1648, 1264, 910,
    600, 345, 156, 39,
    0, 39, 156, 345,
    600, 910, 1264, 1648
};


These example values approximate one sine-wave cycle for a 12-bit DAC.
Step 3: Output the values
The program sends the values to the DAC one by one. Once it reaches the end of the array, it returns to the first sample.
The sample rate determines the output frequency:
\[
f_{\text{wave}}=\frac{f_s}{N}
\]

Where:
- \(f_s\) = sample output rate.
- \(N\) = number of samples per cycle.
For 32 samples per cycle and a sample rate of 3,200 samples per second:
\[
f_{\text{wave}}=\frac{3200}{32}=100\text{ Hz}
\]

A higher sample rate produces a higher waveform frequency if the number of samples per cycle remains the same.











8. DAC + Timer
What does DAC + Timer mean?
DAC + Timer means using a hardware timer to control when each new digital value is sent to the DAC.
Instead of relying on software delays, a timer can trigger DAC conversions at regular intervals.
Why is it useful?
A hardware timer provides more consistent timing than a software loop that may be affected by other processing and interrupts.
How does it work?
1. Configure the DAC.
2. Configure a timer to generate periodic trigger events.
3. Set the DAC to respond to the timer trigger.
4. Each trigger causes the DAC to process the next value, depending on the configuration.
5. Repeating the process generates a waveform with a controlled sample rate.
Example applications
- Generating audio waveforms.
- Producing periodic test signals.
- Creating analog reference patterns.
- Generating signals for control systems.
Remember: The timer controls the timing; the DAC produces the analog voltage.










9. DAC + DMA
What is DMA?
DMA stands for Direct Memory Access. It allows hardware to transfer data between memory and peripherals without requiring the CPU to copy every value manually.
What is DAC + DMA?
DAC + DMA allows a buffer of digital samples to be transferred to the DAC automatically, often triggered by a timer.
This is particularly useful for continuous waveform generation.
How does it work?
1. Store the waveform samples in an array.
2. Configure the DAC.
3. Configure DMA to transfer the samples to the DAC data register.
4. Configure a timer to trigger conversions at a regular rate.
5. Start the timer, DAC, and DMA.
6. The hardware repeatedly outputs the samples according to the configuration.
Example
uint16_t sine_table[32] = {
    /* Precomputed sine-wave samples */
};

/* Illustrative HAL calls; the exact setup
   depends on the STM32 model and HAL version. */

HAL_DAC_Start_DMA(
    &hdac,
    DAC_CHANNEL_1,
    (uint32_t *)sine_table,
    32,
    DAC_ALIGN_12B_R
);


For a continuously repeating waveform, you generally configure DMA in circular mode and configure the DAC's trigger source appropriately. The timer must also be configured and started.
This example is illustrative: the exact API, DMA alignment, data format, and peripheral setup must match the selected MCU.
Why use DAC + DMA?
- Reduces CPU workload.
- Provides consistent sample timing when timer-triggered.
- Supports repeated waveform generation.
- Allows the CPU to perform other tasks while samples are transferred.








10. Polling vs Timer vs DMA for DAC
Method	How it works	Typical use
Polling/software loop	CPU writes each DAC value	Simple experiments
Timer-triggered DAC	Timer controls conversion timing	Consistent periodic output
Timer + DAC + DMA	DMA transfers a sequence of samples at timer-controlled intervals	Continuous waveforms and audio
