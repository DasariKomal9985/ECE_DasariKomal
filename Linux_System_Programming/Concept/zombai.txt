A zombie process is a child process that has already finished execution, but its parent has not yet collected the child's exit status using wait() or waitpid().

👶 Child finishes first → 👨 Parent does not call wait() → 🧟 Child becomes a Zombie

👨 Parent
   │
   └── 👶 Child
          │
          ▼
       finishes
          │
          ▼
   Parent calls wait()
          │
          ▼
     ✅ Cleaned up




#include <stdio.h>
#include <unistd.h>
#include <stdlib.h>

int main()
{
    pid_t pid;

    pid = fork();

    if (pid < 0)
    {
        printf("fork failed\n");
        return 1;
    }

    if (pid == 0)
    {
        // Child Process
        printf("Child PID = %d\n", getpid());
        printf("Child is exiting...\n");

        exit(0);
    }
    else
    {
        // Parent Process
        printf("Parent PID = %d\n", getpid());
        printf("Child PID  = %d\n", pid);

        printf("Parent sleeping for 20 seconds...\n");

        sleep(20);

        printf("Parent exiting...\n");
    }

    return 0;
}


gcc zombie.c -o zombie

Run:

./zombie

You may see:

Parent PID = 5000
Child PID  = 5001
Parent sleeping for 20 seconds...

Child PID = 5001
Child is exiting...


After:

pid = fork();

we have:

             fork()
               │
       ┌───────┴───────┐
       ▼               ▼
   👨 Parent        👶 Child
   PID 5000         PID 5001

The child executes:

exit(0);

So the child finishes.

But the parent executes:

sleep(20);

and hasn't called:

wait(NULL);

Therefore, for that period:

👨 Parent PID 5000
   Still alive
      │
      │ Didn't call wait()
      ▼
🧟 Child PID 5001
   Execution finished
   Exit status waiting
   to be collected

The child is now a zombie.


How to See the Zombie

While the parent is sleeping, open another terminal and run:

ps -el

or:

ps aux

You may see something similar to:

5001  Z   [zombie] <defunct>

Z means:

🧟 Zombie state

You may also see:

<defunct>

which indicates that the process has terminated but has not yet been reaped.


Child terminated
      │
      ▼
Kernel keeps
      │
      ├── PID / process record
      ├── Exit status
      └── Accounting information
             │
             ▼
       Parent calls wait()
             │
             ▼
       Information collected
             │
             ▼
         🧹 Removed

| 👶 Orphan Process         | 🧟 Zombie Process           |
| ------------------------- | --------------------------- |
| Parent terminates first   | Child terminates first      |
| Child is still running    | Child has finished          |
| Original parent is gone   | Parent is still running     |
| Child gets reparented     | Child waits to be reaped    |
| Child continues execution | Child executes no more code |
