PID (Process ID) is a unique numerical identifier assigned by the Linux kernel to a process.
 It is used to identify and manage processes. The current process can obtain its PID using getpid(), while its parent's PID can be obtained using getppid().


 PID = Process ID

A PID is a unique number assigned by Linux to identify a running process. 🐧⚙️

Whenever Linux creates a process, it gives that process a PID.

🔹 Simple Example

Suppose you run:

./program

Linux creates a process:

📦 program
     ↓
🐧 Linux creates process
     ↓
⚙️ Process
     ↓
🆔 PID = 4521

So:

Program  → program
Process  → running instance
PID      → 4521


💻 Get PID Using C

We can use the getpid() system call.

#include <stdio.h>
#include <unistd.h>

int main()
{
    printf("My PID = %d\n", getpid());

    return 0;
}

Compile:

gcc pid.c -o pid

Run:

./pid

Example output:

My PID = 5274

Here:

5274 = PID of this process



🔍 What is getpid()?
getpid()

means:

Get the Process ID of the current process.

For example:

printf("PID = %d\n", getpid());

If the program's PID is 5274:

getpid()
      ↓
    5274
      ↓
printf()
      ↓
PID = 5274



#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid;

    pid = fork();

    if (pid == 0)
    {
        printf("Child PID = %d\n", getpid());
    }
    else
    {
        printf("Parent PID = %d\n", getpid());
        printf("Child PID  = %d\n", pid);
    }

    return 0;
}

Example output:

Parent PID = 5000
Child PID  = 5001

Child PID = 5001

The important thing is:

                👨 Parent
                PID = 5000
                    │
                  fork()
                    │
                    ▼
                👶 Child
                PID = 5001



| Function / value   | Meaning                |
| ------------------ | ---------------------- |
| `getpid()`         | PID of current process |
| `getppid()`        | PID of parent process  |
| `fork()` in parent | Child's PID            |
| `fork()` in child  | `0`                    |
| `fork()` failure   | `-1`                   |
