1. What is Virtual Memory? 🤔
Virtual memory is a memory management technique that gives each process its own virtual address space and allows the operating system to use RAM and storage to manage memory efficiently.
In simple words, a program works with virtual addresses, and the operating system and hardware translate those addresses to physical memory when needed.
💡 Virtual memory is not simply extra RAM. It also provides process isolation and lets programs use an address space that is different from the physical RAM layout.






2. Why Do We Need Virtual Memory?
Imagine your computer has 8 GB of RAM, and multiple applications are running.
- 🌐 Browser
- 💻 VS Code
- 🐧 Ubuntu
- ⚙️ Background services
Each process needs memory. Virtual memory helps the OS manage those memory needs without requiring each program to occupy one continuous block of physical RAM.
Main purposes:
- Give each process its own virtual address space.
- Isolate one process's memory from another's.
- Allow memory to be allocated on demand.
- Map files into memory.
- Support moving eligible pages between RAM and swap when needed.






3. How Does Virtual Memory Work? ⚙️
Process
Uses virtual addresses

MMU + Page Tables
Translate virtual addresses to physical addresses

RAM
Holds resident pages


Storage
Files and optional swap space



Not every memory access involves storage. Most accesses to resident pages are handled through RAM and address translation.

Step-by-step process
1. A program accesses a virtual address.
2. The CPU's MMU checks the address translation, often using the TLB cache.
3. If the mapping is valid and accessible, the CPU accesses the corresponding physical memory.
4. If a page is not currently resident, a page fault may occur.
5. The OS may load or allocate the page, update the mapping, and resume execution. If the access is invalid, the OS may instead report an error to the process.






4. Virtual Memory vs Physical Memory
Feature	Virtual Memory	Physical Memory
Meaning	Address space used by a process	Actual RAM hardware
Addresses	Virtual addresses	Physical addresses
Managed through	OS and MMU	RAM hardware and memory controller
Size	Can exceed available RAM in address-space terms	Limited by installed RAM
Isolation	Provides per-process address-space separation	Shared physical resource among processes
Important: A process having a large virtual address space does not mean all that memory is physically present in RAM or backed by swap.





5. Example of Virtual Memory
Suppose two programs both access virtual address 0x1000.
Process	Virtual address	Physical location
Process A	0x1000	Frame 5
Process B	0x1000	Frame 9
Both processes can use the same virtual address while the OS maps it to different physical frames.
This is one way virtual memory isolates processes from one another.





6. What Is Demand Paging? 📄
Demand paging means a page is brought into physical memory when it is needed, rather than loading every possible page in advance.
For example, when an application starts, not all of its code and data must immediately be loaded into RAM.
If the process accesses a page that is not resident, a page fault may trigger the OS to load it from a file, allocate a new page, or retrieve it from swap, depending on the mapping.
What is a page fault?
A page fault is an event that occurs when the CPU cannot complete a virtual-memory access using the current mapping.
There are different kinds:
- Minor (soft) fault: Can be handled without reading page contents from storage.
- Major fault: Requires storage I/O to bring data into memory.
- Invalid access: May result in a signal such as SIGSEGV.
A page fault is not necessarily a programming error.





7. Virtual Memory and Swap Memory
These two terms are related but different.
Virtual memory	Swap
Provides virtual address spaces and memory mappings	Provides storage space that can hold eligible memory pages
Used even when no swap is configured	Optional on Linux
Supports isolation, demand paging, and file mappings	Can help manage memory pressure
Not equivalent to disk space	Much slower than RAM
When RAM is under pressure, Linux may move eligible anonymous pages to swap. Clean file-backed pages can often be reclaimed and loaded again from their original files.






8. Practical Linux Commands 🐧
Try these commands on Ubuntu.
Check RAM and swap
free -h


Shows total, used, and available memory, along with swap information.
Check virtual memory mappings
cat /proc/self/maps


Displays the current command's memory mappings, including address ranges and permissions.
Check detailed memory statistics
cat /proc/meminfo


Look for fields such as MemTotal, MemAvailable, SwapTotal, and SwapFree.
Check swap devices and files
swapon --show


Displays currently enabled swap areas.





9. Virtual Memory in C Using mmap() 🔧
The POSIX mmap() function can create a mapping in a process's virtual address space.

#include <stdio.h>
#include <string.h>
#include <sys/mman.h>
#include <unistd.h>

int main(void)
{
    size_t size = (size_t)sysconf(_SC_PAGESIZE);

    char *ptr = mmap(NULL, size,
                     PROT_READ | PROT_WRITE,
                     MAP_PRIVATE | MAP_ANONYMOUS,
                     -1, 0);

    if (ptr == MAP_FAILED)
    {
        perror("mmap");
        return 1;
    }

    strcpy(ptr, "Hello from virtual memory!");

    printf("%s\n", ptr);

    if (munmap(ptr, size) == -1)
    {
        perror("munmap");
        return 1;
    }

    return 0;
}



Compile and run:
gcc -Wall -Wextra virtual_memory.c -o virtual_memory
./virtual_memory


Output:
Hello from virtual memory!


How it works
- mmap() creates an anonymous mapping in the process's virtual address space.
- PROT_READ | PROT_WRITE allows reading and writing.
- MAP_PRIVATE | MAP_ANONYMOUS creates a private anonymous mapping, not a file-backed mapping.
- The OS manages the mapping's physical backing as pages are needed.
- munmap() removes the mapping.





10. Virtual Memory vs Paging
Virtual Memory	Paging
A memory-management concept and abstraction	A common technique used to implement virtual memory
Gives processes virtual address spaces	Divides address spaces and physical memory into pages and frames
Supports isolation and memory mapping	Enables page-level address translation





🎯 One-line definition
Virtual memory is a memory-management system that gives processes virtual address spaces and maps their addresses to physical memory, with the OS managing allocation, protection, and page residency.
