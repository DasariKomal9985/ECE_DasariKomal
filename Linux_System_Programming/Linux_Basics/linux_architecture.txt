Linux architecture consists mainly of User Space and Kernel Space. 
User applications run in User Space and access system resources through system calls. 
The Linux kernel manages processes, memory, files, networking, devices, and hardware through components such as device drivers. 
 
 
 
 1️⃣ User Space 👤

User space is where normal applications run with limited privileges.

Examples:

🐚 Bash Shell
💻 C/C++ programs
🌐 Web browser
📁 File manager
📡 Network applications

A user-space program cannot directly access hardware or kernel memory.
For example:

printf("Hello");

Your application requests services from Linux rather than directly controlling the hardware.



2️⃣ System Calls 🔄

System calls provide the interface between User Space and Kernel Space.

When an application needs a privileged service, it makes a system call.

Examples:

open()      → Open a file
read()      → Read data
write()     → Write data
fork()      → Create process
exec()      → Execute another program
wait()      → Wait for child
ioctl()     → Device-specific control

Architecture:

Application
     │
     │ system call
     ↓
  Kernel
     │
     ↓
 Hardware
⭐ Remember:

System call = Gateway between User Space and Kernel Space


3️⃣ Kernel Space ⚙️

Kernel space is the privileged area where the Linux kernel operates.

The kernel manages the computer's resources and provides services to applications.

Major kernel responsibilities include:

🧠 Process Management

Manages:

Processes
Threads
Scheduling
fork()
exec()
wait()
💾 Memory Management

Manages:

RAM
Virtual memory
Paging
Memory allocation
📁 File System

Manages:

Files
Directories
File permissions
File descriptors
🔌 Device Drivers

Communicates with hardware:

UART
I2C
SPI
USB
GPIO
CAN
Storage
Network devices
🌐 Networking

Handles:

TCP/IP
Sockets
Network interfaces
Packets
🔄 IPC

Provides mechanisms such as:

Pipe
Message Queue
Shared Memory
Semaphore
4️⃣ Hardware 💻

At the bottom is the actual physical hardware.

Examples:

🧠 CPU
💾 RAM
💽 SSD/HDD
⌨️ Keyboard
🖥️ Display
🔌 USB
📡 Network adapter
⚡ GPIO
📟 UART
🔗 I2C
🔗 SPI

The kernel communicates with hardware using device drivers.
