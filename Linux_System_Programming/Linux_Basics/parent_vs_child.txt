👨 Parent Process

A parent process is a process that creates another process, usually using fork().

👶 Child Process

A child process is a process created by another process. 
It receives its own PID and initially inherits much of the parent's process state.



1️⃣ What is a Parent Process?

A parent process is a process that creates another process.

In Linux, a parent commonly creates a child using:

fork();

Example:

👨 Parent Process
PID = 1000
     │
     │ fork()
     ▼
👶 Child Process
PID = 1001

Here:

Parent PID = 1000
Child PID = 1001
Parent created the child using fork()


2️⃣ What is a Child Process?

A child process is a process that is created by another process, called its parent.

The child gets its own PID.

👨 Parent
PID = 1000
    │
    └── creates
          │
          ▼
      👶 Child
      PID = 1001

The child can find the PID of its parent using:

getppid();


#include <stdio.h>
#include <unistd.h>

int main()
{
    pid_t pid;

    pid = fork();

    if (pid < 0)
    {
        printf("fork failed\n");
    }
    else if (pid == 0)
    {
        printf("I am Child\n");
        printf("Child PID  = %d\n", getpid());
        printf("Parent PID = %d\n", getppid());
    }
    else
    {
        printf("I am Parent\n");
        printf("Parent PID = %d\n", getpid());
        printf("Child PID  = %d\n", pid);
    }

    return 0;
}

Compile:

gcc parent_child.c -o parent_child

Run:

./parent_child

You might get:

I am Parent
Parent PID = 5000
Child PID  = 5001

I am Child
Child PID  = 5001
Parent PID = 5000


🔥 Understand fork() Carefully

This is the most important part.

pid = fork();

After fork(), there are two processes.

                 Before fork()
                      │
                      ▼
                 👨 Process
                 PID = 5000
                      │
                    fork()
                      │
             ┌────────┴────────┐
             ▼                 ▼
        👨 Parent           👶 Child
        PID = 5000          PID = 5001




But fork() returns different values to each process:

👨 Parent
pid > 0

The return value is the child's PID.

fork() → 5001
👶 Child
pid == 0

The child receives 0 from fork().

❌ Failure
pid == -1

No child was created.


| 👨 Parent Process               | 👶 Child Process                 |
| ------------------------------- | -------------------------------- |
| Creates the child               | Created by parent                |
| Has its own PID                 | Has its own PID                  |
| `fork()` returns child's PID    | `fork()` returns `0`             |
| Can call `wait()` / `waitpid()` | Can execute its own code         |
| Can create more children        | Can also create its own children |
| Can communicate with child      | Can communicate with parent      |
