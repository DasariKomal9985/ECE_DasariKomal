wait()

A system call used by a parent process to wait for a child process to terminate and collect its termination status.

waitpid()

A system call that allows a parent to wait for a specific child process and provides additional control through its options.

🧠 Memory trick

fork() → Create 👶

wait() → Wait ⏳

waitpid() → Wait for THIS child 🎯

exit() → Child finishes 🚪

wait() / waitpid() → Reap child 🧹

   1️⃣ What is wait()?

wait() makes the parent process wait until one of its child processes terminates.

Syntax:

wait(&status);

Include:

#include <sys/wait.h>
Simple meaning:

wait() = "Parent, wait for one of your children to finish."

💻 Basic wait() Example
#include <stdio.h>
#include <unistd.h>
#include <sys/wait.h>

int main()
{
    pid_t pid;

    pid = fork();

    if (pid < 0)
    {
        printf("fork failed\n");
        return 1;
    }

    if (pid == 0)
    {
        // Child
        printf("Child: PID = %d\n", getpid());

        sleep(3);

        printf("Child: Finished\n");
    }
    else
    {
        // Parent
        printf("Parent: PID = %d\n", getpid());

        printf("Parent: Waiting for child...\n");

        wait(NULL);

        printf("Parent: Child finished\n");
    }

    return 0;
}
Example output:
Parent: PID = 5000
Parent: Waiting for child...

Child: PID = 5001
Child: Finished

Parent: Child finished
🔍 What exactly happened?

After:

pid = fork();

we have:

        👨 Parent
        PID 5000
           │
           │ fork()
           ▼
        👶 Child
        PID 5001

The parent executes:

wait(NULL);

So the parent waits.

Meanwhile:

👨 Parent
   │
   │ wait()
   │
   │ 😴 Waiting
   │
   ▼
👶 Child
   │
   │ sleep(3)
   ▼
   Finished

After the child finishes:

👶 Child
   │
   ▼
   exit
   │
   ▼
👨 Parent
   │
   ▼
wait() returns
   │
   ▼
Continue execution
🧟 Why is wait() Important?

Remember the Zombie Process you learned earlier.

If the child terminates but the parent doesn't collect its status:

👶 Child
   │
   ▼
❌ Terminates
   │
   ▼
🧟 Zombie

If the parent does:

wait(NULL);

then:

👶 Child
   │
   ▼
❌ Terminates
   │
   ▼
Parent → wait()
   │
   ▼
🧹 Child reaped

So:

wait() helps prevent/reap zombie children.

2️⃣ What is waitpid()?

waitpid() is a more flexible version of wait().

With wait():

"Wait for a child."

With waitpid():

"Wait for this particular child."

Syntax:

waitpid(pid, &status, options);

Example:

waitpid(child_pid, &status, 0);
💻 Basic waitpid() Example
#include <stdio.h>
#include <unistd.h>
#include <sys/wait.h>

int main()
{
    pid_t pid;
    int status;

    pid = fork();

    if (pid < 0)
    {
        printf("fork failed\n");
        return 1;
    }

    if (pid == 0)
    {
        // Child
        printf("Child: PID = %d\n", getpid());

        sleep(3);

        printf("Child: Finished\n");
    }
    else
    {
        // Parent
        printf("Parent: PID = %d\n", getpid());
        printf("Parent: Child PID = %d\n", pid);

        printf("Parent: Waiting for child...\n");

        waitpid(pid, &status, 0);

        printf("Parent: Child finished\n");
    }

    return 0;
}

Here:

waitpid(pid, &status, 0);

means:

Wait for the child whose PID is stored in pid.

🔥 wait() vs waitpid()
wait()	waitpid()
Waits for a child	Can wait for a specific child
Less control	More control
Simple	More flexible
wait(&status)	waitpid(pid, &status, options)

Think:

wait()
  ↓
"Any child"

waitpid()
  ↓
"This child"
👨‍👦 Multiple Children — Why waitpid() Is Useful

Suppose the parent creates two children:

fork();
fork();

Conceptually:

             👨 Parent
                │
        ┌───────┴───────┐
        ▼               ▼
    👶 Child 1       👶 Child 2
    PID 5001         PID 5002

Suppose you specifically want to wait for Child 2:

waitpid(5002, &status, 0);

The parent waits specifically for:

👶 Child 2
PID = 5002

That's where waitpid() becomes very useful.


💻 Example With Exit Status
#include <stdio.h>
#include <unistd.h>
#include <stdlib.h>
#include <sys/wait.h>

int main()
{
    pid_t pid;
    int status;

    pid = fork();

    if (pid < 0)
    {
        perror("fork");
        return 1;
    }

    if (pid == 0)
    {
        printf("Child: Running...\n");

        sleep(2);

        printf("Child: Exiting with status 10\n");

        exit(10);
    }
    else
    {
        printf("Parent: Waiting for child...\n");

        waitpid(pid, &status, 0);

        if (WIFEXITED(status))
        {
            printf("Parent: Child exited normally\n");
            printf("Parent: Child exit status = %d\n",
                   WEXITSTATUS(status));
        }
    }

    return 0;
}

Output:

Parent: Waiting for child...

Child: Running...
Child: Exiting with status 10

Parent: Child exited normally
Parent: Child exit status = 10
🔍 How Does This Work?

Child:

exit(10);

means:

👶 Child
   │
   ▼
exit(10)
   │
   ▼
Kernel records exit status
   │
   ▼
Parent calls waitpid()
   │
   ▼
status

Then:

WEXITSTATUS(status)

gives:

10
🚦 What Does the 0 Mean in waitpid()?

You will frequently see:

waitpid(pid, &status, 0);

The third argument is options.

When:

0

is used, the parent normally blocks until the selected child changes state, most commonly until it terminates.

For your basic process programs, remember:

waitpid(pid, &status, 0);

means:

Wait for this child and block until it terminates.

⚡ waitpid() Can Also Be Non-Blocking

Later, you'll encounter:

waitpid(pid, &status, WNOHANG);

WNOHANG means:

Don't block if the child hasn't changed state yet.

For example:

Parent
  │
  ▼
waitpid(..., WNOHANG)
  │
  ├── Child finished → collect it
  │
  └── Child still running → return immediately

This is useful in servers, shells, and process managers.




#include <stdio.h>
#include <unistd.h>
#include <sys/wait.h>

int main()
{
    pid_t pid;
    int status;

    pid = fork();

    if (pid == 0)
    {
        printf("CHILD\n");
        printf("PID  = %d\n", getpid());
        printf("PPID = %d\n", getppid());

        sleep(5);

        printf("Child exiting...\n");
    }
    else
    {
        printf("PARENT\n");
        printf("PID       = %d\n", getpid());
        printf("Child PID = %d\n", pid);

        printf("Parent waiting...\n");

        waitpid(pid, &status, 0);

        printf("Parent: waitpid() returned\n");
    }

    return 0;
}

gcc waitpid.c -o waitpid
./waitpid
