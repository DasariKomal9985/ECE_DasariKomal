What is a Program?

A program is a passive set of instructions stored on disk, such as an executable file.

What is a Process?

A process is an active instance of a program that is currently executing and has resources such as a PID, memory, and file descriptors.


🧩 1. What is a Program?

A program is a set of instructions stored in a file.

It is passive — it is just sitting on storage until you execute it.

For example, this C program:

#include <stdio.h>

int main()
{
    printf("Hello Komal!\n");

    return 0;
}

Save it as:

hello.c

Compile it:

gcc hello.c -o hello

Now you have an executable:

hello

That hello executable is a program.

📌 Program = Instructions stored on disk
💾 Storage
   │
   └── hello
       │
       ├── Machine instructions
       ├── Data
       └── Program information

It isn't doing anything until you run it.




⚙️ 2. What is a Process?

A process is a program that is currently executing.

When you run:

./hello

Linux loads the program into memory and creates a process.

💾 Program
   │
   │ ./hello
   ▼
🐧 Linux
   │
   ▼
🧠 Memory
   │
   └── ⚙️ Process
        PID = 1234

The process gets resources such as:

🆔 PID
🧠 Memory
📂 File descriptors
🧮 CPU time
📋 Process state
👤 User/group information



| Program 📦                         | Process ⚙️                  |
| ---------------------------------- | --------------------------- |
| Set of instructions                | Program currently executing |
| Passive                            | Active                      |
| Stored on disk                     | Runs in memory              |
| Does not have a PID                | Has a PID                   |
| Doesn't consume CPU while inactive | Uses CPU when scheduled     |
| Example: `hello` executable        | `./hello` currently running |




💻 Let's See It With Code

Create:

#include <stdio.h>
#include <unistd.h>

int main()
{
    printf("Hello!\n");

    printf("PID = %d\n", getpid());

    sleep(10);

    return 0;
}

Save:

program.c

Compile:

gcc program.c -o program

Here:

program.c
     ↓
   gcc
     ↓
program

program is the program/executable.

Now execute:

./program

Linux creates a process.

You might see:

Hello!
PID = 4521

While sleep(10) is running, the process exists for 10 seconds.

You can check it from another terminal:

ps -p 4521

You may see something like:

    PID TTY          TIME CMD
   4521 pts/0    00:00:00 program

So:

program          → Program 📦
PID 4521         → Process ⚙️
