🚀 Introduction to C++ Programming

C++ is a general-purpose programming language used to develop applications, system software, embedded software, games, and many other programs.
C++ is an extension of C that supports both procedural programming and Object-Oriented Programming (OOP).


1. 🧠 What is C++?
- 💻 C++ — A programming language used to write instructions for computers.
- ⚙️ Compiler — Converts C++ source code into machine code.
- 📦 Header files — Provide declarations for features such as input and output.
- 🖨️ cout — Displays output.
- ⌨️ cin — Takes input from the user.
- 🔧 main() — The starting point of a C++ program.



C vs. C++

Feature	C	C++
Input/output	printf(), scanf()	cout, cin
Header example	stdio.h	iostream
Programming style	Procedural	Procedural and OOP
Classes and objects	No built-in support	Supported
File extension	.c	.cpp
